Mean can be calculated for numeric and logical variables, but character
and factor variables return NA

``` r
as.numeric(pull(x, log_var))
as.numeric(pull(x, char_var))
as.numeric(pull(x, factor_var))
```

True and False in logical variables are converted to 1 and 0, but
Character variables return NA because letters cannot be converted to
numbers. For the factor variable, their underlying integers can also be
converted.
